### Exercise 4: Interactive Profile Card

I styled the profile card elements using CSS selectors and pseudo-classes. I grouped the `h2`, `p`, and `button` selectors to give them consistent spacing, styled the button with a dark blue background and white text, and added a `:hover` effect so the button turns red and slightly grows when the user hovers over it.

I also styled the input with a gray border and used `:focus` to change the border to blue when the user clicks into it. Finally, I targeted `#user-name` directly to remove its default margin.
