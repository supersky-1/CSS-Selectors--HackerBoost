### Exercise 6: Reconstruct from Scratch

In this exercise, I created a simple news sidebar with a heading and a list of linked news stories. The HTML uses a `.sidebar` container, an `id` for the sidebar title, and a list of links for the news items.

In the CSS, I targeted links inside the sidebar with `.sidebar a` to remove the underline and make them dark blue. I also used the `:hover` pseudo-class so the links turn red when the user moves the mouse over them.
